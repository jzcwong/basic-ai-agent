# Introduction
This is based on https://github.com/balapriyac/ai-agent-from-scratch and the companion article https://machinelearningmastery.com/how-and-why-to-build-an-ai-agent-from-scratch-in-python/ 

## Key components
- uses Anthropic Haiku 5.5 model
- Tool call
- Memory

## Pre-requisites

```bash
uv pip install anthropic
```

```bash
export ANTHROPIC_API_KEY="your-key-here"
```

## To run it
```bash
python agent.py
```
